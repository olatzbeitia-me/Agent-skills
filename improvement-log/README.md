# Improvement log

Each agent in this repository is reviewed in turn against current expert practice. Every review leaves one file here, named `<YYYY-MM-DD>-<agent>.md`, recording:

- the date and the agent reviewed;
- what changed, and why;
- what was considered and rejected;
- the sources behind the change, with titles and links.

Reviews are chosen least recently reviewed first, so the dates in this folder show how current each agent is. A review that finds nothing worth changing is still logged, because a deliberate "no change" is better than a cosmetic one.

Changes arrive as pull requests on branches named `improve/<YYYY-MM-DD>-<agent>` and are merged only after a human review.
